# AEGIS entry and recording guide

Our current [submission text](../SUBMISSION_COPY.md) contains the description, go-to-market plan and three sponsor answers. The README is the source for the current deployment status.

## Videos

The main technical demo can be up to 3 minutes. Show the working site, wallet connection, an access request and its result, then the employee view of the evidence. Label replay examples as simulated. Show actual signing before describing that flow as verified. Keep the employee key and provider settings out of the recording.

The pitch can be up to 2 minutes. Introduce our six-person team: a lead developer who also handles business operations, two backend developers and three frontend developers. Explain the wallet-access problem, show what AEGIS adds and describe our plan for enterprise pilots.

Optional sponsor videos can be up to 2 minutes each. For Envio, show activity becoming features. For Alchemy, show chain and block verification. For Dynamic, show wallet connection and signing. Use real evidence when claiming a live integration.

## Before submitting

Add the demo and pitch links, check that the website and repository open, and keep judge credentials in the private access-instructions field. Save progress, then use Submit to complete the entry. Saving alone does not submit it.

The older Word packs are archived drafts. Use the current Markdown documentation for the latest wording and deployment status.
